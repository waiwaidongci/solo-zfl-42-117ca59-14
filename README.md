# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

## 作品流转

- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出。

## 防伪证书与产权转移台

针对已交付（待交付）作品：

- **签发证书**：证书绑定作品特征指纹（SHA-256）、唯一编号（ZFL-年份-序号）、持有人及份额、签发时间；签发后不能覆盖，同一作品已有有效证书时拒绝重复签发。
- **产权转移**：持有人本人发起转移单，受让方本人确认后产权才变更，且只能变更一次。两页同时提交、重复确认、越权操作（非本人发起/确认）、证书冻结或已撤销时一律拒绝。
- **共有份额**：支持多名持有人按份额共有，各自份额可分别转移；同一持有人的待确认份额累计不得超过其持有份额。
- **质押冻结**：持有人可办理质押冻结（记录质权人与事由），冻结期间一切转移、确认与撤销均被拒绝，解冻后恢复。
- **撤销重签**：仅当前持有人可撤销或重签证书（非持有人、已无份额的原持有人、冻结中的证书一律拒绝，拒绝后证书状态与台账不变）；撤销留原因，原证保留在历史中，重签新证承接持有人并标记来源。
- **继承过户**：转移类型可选继承过户，凭公证号留痕，同样需继承人确认。
- **完整台账**：签发、转移、确认、冻结、解冻、撤销、重签、导入全部追加哈希链台账，历史不能重算。
- **校验真伪**：任一历史证书（含已撤销）均可按编号校验——重算特征指纹、证书签章、证书链，并从台账逐条回放比对当前持有人与状态；篡改存储中任何字段都会判伪，台账链可单独校验。
- **旧作品补发**：旧版 `zfl42Works` 数据自动迁移，旧已交付作品可补发证书（带补发标记），作品原始历史日志保持不变。
- **原子与一致**：每次变更经跨页互斥锁（Web Locks，含降级方案）在最新状态上校验后一次性写入，要么完整成功要么全部不写；刷新、导出、导入恢复后证书与产权保持一致。导入备份先完成格式、台账哈希链、证书指纹与签章、产权关系（台账回放比对）四项校验，任一项失败则当前作品、证书、转移单与台账保持原样并提示失败原因。

## 浏览器端到端测试

`tests/run.mjs` 使用 Playwright 驱动真实 Chromium，覆盖签发、份额校验、越权与重复确认、两页并发提交/确认、共有份额分别转移、质押冻结与解冻、撤销重签、存储篡改校验、旧数据补发、刷新/导出/恢复一致性，以及销毁授权边界（攻击者撤销、无份额主体撤销、冻结中撤销/重签、非持有人重签）和导入校验（格式错误、哈希链篡改、证书篡改、产权关系篡改、正常导入）：

```bash
npm install        # 安装 playwright
npx playwright install chromium
node tests/run.mjs
```
